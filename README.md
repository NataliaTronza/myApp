# Стати — як встановити на телефон

APK тут немає, і він не потрібен. Це **PWA** — вебзастосунок, який Android встановлює
як звичайну програму: своя іконка на екрані, повноекранний режим без адресного рядка,
робота офлайн. Візуально від нативного не відрізняється.

Головна умова: файли мають лежати на сайті з **https**. Локальний файл на телефоні
теж відкриється, але без іконки, без офлайн-режиму й з ненадійним збереженням даних.

---

## Що в комплекті

| Файл | Навіщо |
|---|---|
| `index.html` | сам застосунок |
| `manifest.webmanifest` | назва, іконка, режим запуску |
| `sw.js` | офлайн-режим |
| `icon-192.png`, `icon-512.png` | іконки |
| `icon-maskable-512.png` | іконка під круглі/квадратні маски Android |
| `apple-touch-icon.png` | іконка для iPhone |
| `favicon.png` | іконка вкладки в браузері |

**Усі файли мають лежати в одній папці.** Не перейменовуй їх.

---

## Спосіб 1. GitHub Pages — рекомендований

Ти вже робила так із DuckUI, тож кроки знайомі.

1. Створи репозиторій, наприклад `staty`.
2. Завантаж туди **всі файли з архіву**, у корінь (не в підпапку).
3. Settings → Pages → Source: `Deploy from a branch`, гілка `main`, папка `/ (root)`. Save.
4. Через 1–2 хвилини зʼявиться адреса виду `https://ТВІЙ_НІК.github.io/staty/`.
5. Відкрий цю адресу **в Chrome на телефоні**.
6. Меню (⋮) → **«Встановити застосунок»** або «Додати на головний екран».
7. Готово — іконка на робочому столі, запуск на весь екран.

Якщо пункт «Встановити застосунок» не зʼявився: онови сторінку, зачекай кілька секунд
(має зареєструватися `sw.js`) і перевір, що адреса саме `https://`, а не `http://`.

## Спосіб 2. Без GitHub

Підійде будь-який статичний хостинг: Netlify Drop (перетягуєш папку — і готово),
Cloudflare Pages, Vercel. Далі так само: відкрити адресу в Chrome → «Встановити застосунок».

## Спосіб 3. Просто файл на телефоні

Кинь `index.html` у памʼять телефону й відкрий через файловий менеджер.
Працюватиме, але **без іконки, без офлайн-кешу**, і дані можуть загубитися при чищенні
браузера. Годиться хіба щоб швидко глянути.

---

## Перенести прогрес із компʼютера

Дані зберігаються в браузері конкретного пристрою й **не синхронізуються самі**.

1. На компʼютері: ⚙ → **Експорт** → збережеться файл `staty-РРРР-ММ-ДД.json`.
2. Перекинь його на телефон (пошта, месенджер, хмара — байдуже).
3. На телефоні у застосунку: ⚙ → **Імпорт** → вибери цей файл.

Роби експорт раз на тиждень — це водночас і бекап.

---

## Оновити застосунок пізніше

Заміни файли в репозиторії на нові. Застосунок підхопить оновлення при наступному
запуску (іноді потрібно відкрити двічі — перший раз кеш оновлюється у фоні).
Дані при оновленні не зникають.

Якщо колись знадобиться повністю скинути кеш: Налаштування Android → Застосунки →
Стати → Сховище → «Очистити кеш». **Не тисни «Очистити дані»** — це зітре прогрес.

---

## Дрібниці, які варто знати

- Прогрес живе в памʼяті браузера. Видалення застосунку = видалення даних. Тримай свіжий експорт.
- Передбачення оновлюється раз на добу, при першому відкритті.
- Штрафи нараховуються за минулі дні при відкритті — навіть якщо не заходила тиждень,
  усе порахується коректно.
- Темп прокачки й розмір штрафу міняються в ⚙ без правки коду.
