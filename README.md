# Waymark — як встановити на телефон

APK тут немає, і він не потрібен. Це **PWA** — вебзастосунок, який Android встановлює
як звичайну програму: своя іконка на екрані, повноекранний режим без адресного рядка,
робота офлайн. Візуально від нативного не відрізняється.

Головна умова: файли мають лежати на сайті з **https**. Локальний файл на телефоні
теж відкриється, але без іконки, без офлайн-режиму й з ненадійним збереженням даних.

---

## Що в комплекті

| Файл | Навіщо |
|---|---|
| `index.html` | сам застосунок |
| `manifest.webmanifest` | назва, іконка, режим запуску |
| `sw.js` | офлайн-режим |
| `icon-192.png`, `icon-512.png` | іконки |
| `icon-maskable-512.png` | іконка під круглі/квадратні маски Android |
| `apple-touch-icon.png` | іконка для iPhone |
| `favicon.png` | іконка вкладки в браузері |

**Усі файли мають лежати в одній папці.** Не перейменовуй їх.

---

## Спосіб 1. GitHub Pages — рекомендований

Ти вже робила так із DuckUI, тож кроки знайомі.

1. Створи репозиторій, наприклад `staty`.
2. Завантаж туди **всі файли з архіву**, у корінь (не в підпапку).
3. Settings → Pages → Source: `Deploy from a branch`, гілка `main`, папка `/ (root)`. Save.
4. Через 1–2 хвилини зʼявиться адреса виду `https://ТВІЙ_НІК.github.io/staty/`.
5. Відкрий цю адресу **в Chrome на телефоні**.
6. Меню (⋮) → **«Встановити застосунок»** або «Додати на головний екран».
7. Готово — іконка на робочому столі, запуск на весь екран.

Якщо пункт «Встановити застосунок» не зʼявився: онови сторінку, зачекай кілька секунд
(має зареєструватися `sw.js`) і перевір, що адреса саме `https://`, а не `http://`.

## Спосіб 2. Без GitHub

Підійде будь-який статичний хостинг: Netlify Drop (перетягуєш папку — і готово),
Cloudflare Pages, Vercel. Далі так само: відкрити адресу в Chrome → «Встановити застосунок».

## Спосіб 3. Просто файл на телефоні

Кинь `index.html` у памʼять телефону й відкрий через файловий менеджер.
Працюватиме, але **без іконки, без офлайн-кешу**, і дані можуть загубитися при чищенні
браузера. Годиться хіба щоб швидко глянути.

---

## Перенести прогрес із компʼютера

Дані зберігаються в браузері конкретного пристрою й **не синхронізуються самі**.

1. На компʼютері: ⚙ → **Експорт** → збережеться файл `waymark-РРРР-ММ-ДД.json`.
2. Перекинь його на телефон (пошта, месенджер, хмара — байдуже).
3. На телефоні у застосунку: ⚙ → **Імпорт** → вибери цей файл.

Роби експорт раз на тиждень — це водночас і бекап.

---

## Оновити застосунок пізніше

Заміни файли в репозиторії на нові. Застосунок підхопить оновлення при наступному
запуску (іноді потрібно відкрити двічі — перший раз кеш оновлюється у фоні).
Дані при оновленні не зникають.

Якщо колись знадобиться повністю скинути кеш: Налаштування Android → Застосунки →
Waymark → Сховище → «Очистити кеш». **Не тисни «Очистити дані»** — це зітре прогрес.

## Як усе влаштовано

**Стати — девʼять:** Сила, Здоровʼя (харчування, вода, таблетки, сон), Турбота (зовнішність, SPF, макіяж,
приємні дрібниці), Порядок, Творчість, Розум, Мови, Спілкування, Стійкість (психологія, внутрішній стан).
Для Здоровʼя, Мов і Спілкування звання поки чернеткові, а тексти рівнів ще не написані — вікно показує
лише «Тепер ти …». Тексти лежать в `index.html` у блоці `FLAVOR`.

**Ритм у кожної стати свій** (⚙ → Ритм стат):
- *щодня* — штраф за день без жодного бала, далі ×2, ×3, ×4, якщо пропуски поспіль;
- *норма на тиждень* — скільки балів набрати за тиждень (Сила — 80). У неділю, якщо не добрано,
  штраф за кожні 10 недобраних балів; кілька провалених тижнів поспіль — штраф росте;
- *полоска* — стан, який щодня просідає сам (Порядок — на 10 зі 100). Бали за прибирання її наповнюють.
  Рівень Порядку не падає, поки полоска не на нулі;
- *без штрафів* — бали, рівні й серії як завжди, тільки нічого не списується (Спілкування).
Будь-яка зміна — ритму, норми чи розміру штрафу — діє з того дня, коли її зробили. Минуле не перераховується.

**Штрафи** зберігаються окремо від заробленого й перераховуються за останній тиждень. Тому ретро-відмітка
(«Забула відмітити?» у завданні) сама повертає штраф за той день, а для тижневої норми — дораховує бали.

**Серії й нагороди.** Для щоденних стат серія — днів поспіль від 10 балів (окремо від 20).
Для тижневих — тижнів поспіль із виконаною нормою. «Усі одразу» рахуються по стати з щоденним ритмом.
Нагороди за серії, рівні й суму балів нараховуються самі й дають бонусні бали, які не йдуть у денний журнал.

**Мої досягнення** — вкладка «Досягнення» → «+ нове»: своя назва, стати й ціна. Бувають разові та повторювані.

**Квест дня** — картка вгорі «Завдань». Один на день, з множником балів (⚙). Квести бувають трьох видів:
нове завдання, посилання на завдання зі списку (бонус поверх звичайних балів) і набір дій
(бонус за кілька завдань певної стати, можна з вікном часу).

**Мапа — силует персонажа.** Під мапою можна вибрати тінь: якою ти була тиждень або місяць тому.
Зелені «+1» біля рівнів — скільки виросло за цей час. Тінь зʼявляється, коли накопичиться відповідна історія.

**Рік у клітинках** — кнопка ◴ угорі. Кожен день — квадратик, чим темніший, тим більше балів.
Можна дивитися всі стати разом або одну; торкнись дня — побачиш деталі.

**Підсумок тижня** зʼявляється в понеділок при першому відкритті: найкращий день, що росло й що просіло,
норми, полоска, нові рівні, квести. Його також можна відкрити з «Року в клітинках».

**Збереження.** Застосунок просить браузер не чистити його дані. Перед кожним оновленням формату
браузер відкладає копію старих даних, і якщо збережене раптом не прочитається, воно теж не зникне:
у ⚙ зʼявиться кнопка «Повернути дані до оновлення». Якщо файлової копії прогресу немає або вона
старша за тиждень, на «Мапі» є нагадування з кнопкою «Зберегти».

Інше:
- Передбачення оновлюється раз на добу, при першому відкритті.
- Темп прокачки, тема, розмір штрафу, ритм стат і множник квесту міняються в ⚙ без правки коду.
- «Скинути прогрес» обнуляє рівні й журнал, але лишає завдання, квести, досягнення й налаштування.
- Тем пʼять: Небо, Світанок, Веселка, Гай і темна Ніч.
